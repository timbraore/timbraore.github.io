# TimbraOre

**Orari, banca ore, ferie e permessi per chi lavora nella PA.**

Strumento gratuito e **non ufficiale** per tenere sotto controllo l'orario di lavoro: calcola l'orario di uscita, il buono pasto, la banca ore e i saldi dei giustificativi (ferie, festività soppresse, permessi, lavoro agile).

- I dati restano sul tuo dispositivo: non c'è nessun server e nessuna raccolta di dati.
- Le regole di calcolo (orario, pausa, buono pasto, competenze) si modificano da **Impostazioni**, quindi funziona anche con orari diversi.
- Non è collegato ad alcuna amministrazione e non registra timbrature ufficiali: fa sempre fede il sistema ufficiale di rilevazione presenze.

Sito: https://timbraore.github.io

Per segnalare un errore o proporre un miglioramento apri una *Issue*. Non inserire dati personali nelle segnalazioni.
